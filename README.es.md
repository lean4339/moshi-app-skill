# Moshi · App Skill

**Un protocolo autocontenido con integraciones opcionales de diario e informes.**

[English](README.md) · **Español**

La skill incluida en la aplicación Moshi, conservada como paquete separado. Describe acompañamiento emocional respetuoso y no profesional, autonomía y registros personales opcionales mediante las herramientas MCP de la aplicación.

## Qué cubre

| Área | Guía |
| --- | --- |
| Conversación | Adaptarse al idioma y las preferencias de la persona, con una acción abordable por vez. |
| Diario opcional | Documentar entradas con consentimiento, preferencias, correcciones y borrados mediante las herramientas MCP disponibles. |
| Informes para consultas | Preparar un resumen fiel para revisión de la persona antes de llamar al exportador PDF de la aplicación. |

## Primeros pasos

Leé [SKILL.md](SKILL.md) y después las referencias pertinentes. Dale a un agente compatible acceso al paquete y a los archivos autorizados. Conservá las carpetas adyacentes a SKILL.md; copiar solamente ese archivo puede romper sus referencias.

### Requisitos

Un agente compatible para las instrucciones conversacionales. El diario y los PDF requieren además la aplicación Moshi separada y sus herramientas MCP configuradas. El paquete contiene solamente SKILL.md y documentación del repositorio.

### Ejemplo de pedido

> Revisá el flujo de diario de Moshi: identificá dónde se requiere consentimiento y cómo se revisa un informe antes de exportarlo. Es una revisión técnica, no un pedido de apoyo emocional.

## Alcance y límites

Es un protocolo experimental de apoyo no profesional, no diagnóstico, tratamiento ni servicio de emergencias. No se incluyen diarios personales, perfiles, PDF ni bases de datos. Documentar o configurar la skill no activa una conversación de apoyo. El empaquetado no realizó validación clínica ni de comportamiento.

El README está disponible en inglés y español, como la documentación de Huella. Los SKILL.md y las referencias conservan su idioma y redacción originales.
