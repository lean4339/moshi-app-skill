# Moshi · App Skill

**A self-contained support protocol with optional journal and report integrations.**

**English** · [Español](README.es.md)

The skill bundled with the Moshi application, preserved as a separate package. It describes respectful, non-professional emotional support, user choice and optional personal records through the application’s MCP tools.

## What it covers

| Area | Guidance |
| --- | --- |
| Conversation | Adapt to the person’s language and preferences, with one manageable action at a time. |
| Optional journal | Document consent-based entries, preferences, corrections and deletion through the available MCP tools. |
| Consultation reports | Prepare a faithful summary for user review before calling the application’s PDF exporter. |

## Start here

Read [SKILL.md](SKILL.md), then the references relevant to the task. Give a compatible agent access to this package and the authorized target files. Keep adjacent directories with SKILL.md; copying that file alone can break its references.

### Requirements

A compatible agent for the conversational instructions. Journal and PDF functions additionally require the separate Moshi application and its configured MCP tools. The package contains only SKILL.md and repository documentation.

### Example request

> Review the Moshi journal workflow: identify where consent is required and how a report is reviewed before export. Treat this as a technical review, not a request for emotional support.

## Scope and limits

This is an experimental, non-professional support protocol, not a diagnosis, treatment or emergency service. No personal journal, user profile, PDF or database is included. Documenting or configuring the skill does not activate a support conversation. No clinical or behavioral validation was performed during packaging.

The README is available in English and Spanish, matching Huella’s documentation. Original SKILL.md files and references retain their source language and wording.
